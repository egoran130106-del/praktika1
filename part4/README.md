## Запуск

Нужен JDK 8 или новее. Откройте папку в IntelliJ IDEA и запустите нужный класс с main.
Или в терминале этой папки:

```text
javac -encoding UTF-8 *.java
java ИмяКласса
```

Каждое задание запускается отдельно. В больших заданиях вспомогательные классы вложены в главный класс и помечены static: их можно создавать из main без дополнительного объекта главного класса. Алгоритмы используют обычные циклы и методы.

## Часть 4, раздел 4.1, задание 8 и упражнение 1: абстрактные фигуры

Файл: [Section41Task08Shapes.java](Section41Task08Shapes.java). Класс запуска: `Section41Task08Shapes`.


Полиморфизм: ссылка типа Shape хранит Circle, Rectangle или Square.
Для getArea(), getPerimeter() и toString() выполняется реализация фактического объекта.
Для Circle(5.5) площадь примерно 95.0332, периметр 34.5575.
Для Rectangle(1, 2) площадь 2, периметр 6; для Square(6.6) площадь 43.56.

Ошибки исходного примера:
- `s1.getRadius()` — у типа Shape нет getRadius(); используем c1 после приведения.
- `new Shape()` — абстрактный класс нельзя создать.
- `s3.getLength()` — сначала приводим ссылку к Rectangle.
- `s4.getSide()` и `r2.getSide()` — getSide() объявлен только в Square.
Приведение допустимо, только если объект действительно имеет нужный тип.
Здесь типы известны из конструкторов; неверное приведение вызовет ClassCastException.
Значения color по умолчанию взяты из примера PDF: blue, filled=false.
Размеры фигур в примерах положительные.
