# Проверка решений

Проверка выполнена 23 октября 2026 года.

- Все 23 исходных Java-файла скомпилированы для Java 8 (Eclipse ECJ 3.26.0).
- Все 22 программы с main запущены на Java 8 без ошибок.
- После объединения вспомогательных классов в файлы заданий вывод сравнен с исходными версиями: совпадает.
- Проверены суммы и среднее массива, оба способа суммирования, минимум и максимум.
- Проверены массив из одного числа, отрицательные числа и нулевой размер.
- Проверены факториалы 0, 5 и 20; числа -1 и 21 отвергаются.
- Проверены аргументы командной строки и крайние члены гармонического ряда.
- Проверены результаты сложения и умножения матриц.
- Проверены зарплата и доплата менеджера по выбранному толкованию условия.
- Для магазина проверены неверный вход, каталоги, добавление товара, сумма покупки,
  очистка корзины, пустая корзина и ошибочные пункты меню.

Это учебные примеры. Полноценная проверка произвольного текстового ввода в заданиях
1.4 и 1.7 не добавлялась: там ожидаются целые числа, как указано в инструкции.
