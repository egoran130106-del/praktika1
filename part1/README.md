# ПР1 часть 1.pdf — решения

Пункты 1, 2 и 8 относятся к созданию проекта, репозиторию и показу преподавателю. Репозиторий создан, код загружен через GitHub. Для пункта про IDE откройте эту папку в IntelliJ IDEA, выберите JDK и запустите нужный класс. Демонстрацию преподавателю нужно сделать самостоятельно.

## Запуск

Нужен JDK 8 или новее. Откройте папку в IntelliJ IDEA и запустите нужный класс с main.
Или в терминале этой папки:

```text
javac -encoding UTF-8 *.java
java ИмяКласса
```

Каждое задание запускается отдельно. В больших заданиях вспомогательные классы вложены в главный класс и помечены static: их можно создавать из main без дополнительного объекта главного класса. Алгоритмы используют обычные циклы и методы.
